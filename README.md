# سَنَد — بوت دعم فني لا يخترع إجابات

[English](README.en.md)

**يدخل سؤال الموظف بالعربية أو بالإنجليزية، ويطلع رد معتمد — أو «لا أعرف» بصراحة.**

خادم Node.js واحد: 12,455 سطر كود (من غير التبعيات)، 6 حزم npm بس، 40 اختبار E2E، و 19 جدول SQLite.

ينظّف السؤال، يقارنه بقاعدة إجابات راجعها بشر، ثم يرد. الـ LLM ممنوع يكتب رد المستخدم. هذا حد مفروض في الكود، مو سطر في التوثيق.

يشتغل بدون إنترنت. نموذج الـ embeddings محلي بالكامل (130 ميجابايت جوّه `data/models`).

---

## المشكلة

الموظفين يسألون الدعم الفني نفس الأسئلة كل يوم: كلمة المرور، الطابعة، رصيد الإجازات.

الحل الواضح بوت مبني على LLM. بس الـ LLM ما يعرف الأنظمة الداخلية، فيخترع خطوات شكلها صح.

لو نفّذ موظف خطوة مخترعة على نظام production، صارت عندك مشكلة أكبر من سؤاله الأول.

سَنَد يقلب الترتيب: المطابقة أول، و«ما أعرف» رد مقبول.

---

## كيف يشتغل

**1. تطبيع عربي.** يشيل التشكيل والتطويل. يوحّد `أ إ آ ٱ` إلى `ا`، و `ة` إلى `ه`، و `ى` إلى `ي`. يحوّل الأرقام العربية إلى غربية. بعدها يبدّل المرادفات المحفوظة، مثل `باسورد` تصير `كلمة المرور`.

**2. مطابقة هجينة.** يحسب درجتين منفصلتين، والأعلى يفوز:

| الطبقة | الحساب | الغرض |
|---|---|---|
| لفظية | `0.5 × Jaccard` على الكلمات + `0.5 × Dice` على trigrams الحروف | صياغة قريبة |
| دلالية | cosine similarity على embeddings بـ 384 بُعداً (MiniLM متعدد اللغات، ONNX q8) | نفس المعنى بكلمات ثانية |

**3. ثلاث عتبات.** هنا يصير القرار كله:

| الدرجة | التصرّف |
|---|---|
| 0.85 فأعلى | يرد بالإجابة المعتمدة، **ويحفظ صيغة السؤال الجديدة** تلقائياً |
| 0.55 إلى 0.85 | يعرض «هل تقصد؟» بثلاثة عناوين، ويمرّر الحالة لحَكَم يشتغل في الخلفية |
| أقل من 0.55 | يقول «ما أعرف»، ويحط السؤال في طابور المدرّب |

### إثبات: الطبقة اللفظية وحدها، بلا قاعدة بيانات وبلا متجهات

```
in  : "كيف أُغيِّرُ كَلِمَةَ المُرورِ؟"  |  "كيف اغير كلمة المرور"
norm: "كيف اغير كلمه المرور"        |  "كيف اغير كلمه المرور"
lang=ar  score=1.000   -> رد فوري

in  : "الطابعه ما تطبع"             |  "الطابعة لا تطبع"
norm: "الطابعه ما تطبع"             |  "الطابعه لا تطبع"
lang=ar  score=0.583   -> "هل تقصد؟"

in  : "كم رصيد إجازاتي؟"            |  "وش رصيد الاجازات"
norm: "كم رصيد اجازاتي"             |  "وش رصيد الاجازات"
lang=ar  score=0.481   -> "لا أعرف" + طابور
```

المثال الثالث يوضّح ليش فيه طبقة دلالية: السؤالين معناهم واحد، ودرجتهم اللفظية 0.481 بس.

## أهم قرار في التصميم

**المشكلة:** أي بوت دعم مبني على LLM بيخترع إجابات عن أنظمة ما شافها.

**القرار:** مسار الرد الحي ما يستدعي الـ LLM أبداً. مو قاعدة تشغيل، هذي بنية. ملف `lib/engine.js` وملف `routes/chat.js` فيهم 0 استدعاء لـ `callBrain`، وما يستوردون `lib/brain.js` أصلاً. الملف مستورد في 4 مواضع بس، كلها برا مسار الرد: عامل خلفية، ومدرّب، وممتحِن، ولوحة التدريب.

**التكلفة:** البوت ما يجاوب إلا على اللي تدرّب عليه، وقاعدة الإجابات تبدأ بـ 0 إجابة.

**العائد:** 0 إجابة مخترعة، و 0 طلب شبكة في مسار الرد. الرد يطلع من SQLite محلية.

الـ LLM يشتغل ورا الكواليس بس، وبشكل async: يحكم على المطابقات المتوسطة وحكمه ينحفظ في cache، ويقترح صياغات بديلة **يوافق عليها المدرّب**، ويترجم النصوص.

## التشغيل

```bash
npm install     # ينزّل نموذج المتجهات مرة واحدة إلى data/models
npm start       # http://127.0.0.1:4600
npm run verify  # 40 اختبار E2E على قاعدة مؤقتة، ثم يحذفها
```

الخادم يسمع على `127.0.0.1` بس، مو على كل الواجهات.

| المتغير | الوظيفة |
|---|---|
| `PORT` | المنفذ. الافتراضي 4600 |
| `SANAD_DB` | مسار قاعدة SQLite |
| `SANAD_NO_BRAIN=1` | يوقف كل استدعاءات الـ LLM. وضع الاختبار |
| `SANAD_NO_EMBED=1` | يوقف الـ embeddings، ويخلي المطابق اللفظي وحده |
| `SANAD_BRAIN_CMD` | أمر الـ LLM الخارجي. ياخذ النص كأول وسيط ويطبع JSON. فاضي = ما فيه استدعاء أبداً |
| `SANAD_BRAIN_ARGS` | وسائط إضافية بعد النص. الافتراضي `--json` |
| `SANAD_TG_TOKEN` | توكن بوت تيليجرام. اختياري، وما يظهر في أي سجل |
| `SANAD_TG_ALLOWLIST` | المحادثات المسموح لها. اللي غيرها يتسجّل ويترفض |
| `SANAD_TG_ADMIN` | معرّف محادثة المدرّب |

كل الأسرار تجي من البيئة. ما فيه مفتاح واحد داخل الكود.

قناة تيليجرام محدودة بـ 20 رسالة في الدقيقة لكل محادثة. الخادم ياخذ نسخة احتياطية كل 24 ساعة، ويحتفظ بآخر 14 نسخة.

## لماذا بنيته

أشتغل مشرف تقنية معلومات. الدعم يعيد نفس الإجابات كل يوم.

بنيت المحرّك بس: قاعدة الإجابات تبدأ بـ 0 إجابة، وكل جهة تعبّيها بمحتواها هي.
