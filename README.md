# سَنَد — بوت دعم فني لا يخترع إجابات

[English](README.en.md)

**سؤال موظف بالعربية أو الإنجليزية يدخل — إجابة موثّقة تخرج، أو «لا أعرف» صريحة.**

خادم Node.js واحد: 12,455 سطر مصدر (بلا عدّ التبعيات)، و 6 حزم npm فقط، و 40 اختبار E2E، و 19 جدول SQLite.

يطبّع السؤال، يطابقه بقاعدة إجابات معتمدة بشرياً، ثم يرد. النموذج اللغوي ممنوع من كتابة رد المستخدم. هذا حدّ في الكود، لا سطر في التوثيق.

يعمل بلا إنترنت. نموذج المتجهات محلي بالكامل (130 ميجابايت داخل `data/models`).

---

## المشكلة

الموظف يسأل الدعم الفني نفس الأسئلة كل يوم: كلمة المرور، الطابعة، رصيد الإجازات.

الحل الواضح بوت مبني على نموذج لغوي. لكن النموذج لا يعرف الأنظمة الداخلية. فيخترع خطوات تبدو صحيحة.

موظف ينفّذ خطوة مخترعة على نظام إنتاج مشكلة أكبر من سؤاله الأصلي.

سَنَد يعكس الترتيب: المطابقة أولاً، والاعتراف بالجهل خيار مقبول.

## كيف يشتغل

**1. تطبيع عربي.** يحذف التشكيل والتطويل. يوحّد `أ إ آ ٱ` إلى `ا`، و `ة` إلى `ه`، و `ى` إلى `ي`. يحوّل الأرقام العربية إلى غربية. ثم يستبدل المرادفات المخزّنة، مثل `باسورد` إلى `كلمة المرور`.

**2. مطابقة هجينة.** درجتان مستقلتان تُحسبان، والأعلى يفوز:

| الطبقة | الحساب | الغرض |
|---|---|---|
| لفظية | `0.5 × Jaccard` على الكلمات + `0.5 × Dice` على ثلاثيات الحروف | صياغة قريبة |
| دلالية | جيب التمام على متجهات 384 بُعداً (MiniLM متعدد اللغات، ONNX q8) | معنى واحد بكلمات مختلفة |

**3. ثلاث عتبات.** هنا القرار كله:

| الدرجة | التصرّف |
|---|---|
| 0.85 فأعلى | يرد بالإجابة المعتمدة، **ويحفظ صيغة السؤال الجديدة** تلقائياً |
| 0.55 إلى 0.85 | يعرض «هل تقصد؟» بثلاثة عناوين، ويرسل الحالة إلى حَكَم يعمل في الخلفية |
| أقل من 0.55 | يعترف أنه لا يعرف، ويضع السؤال في طابور المدرّب |

### إثبات: الطبقة اللفظية وحدها، بلا قاعدة بيانات وبلا متجهات

```
in  : "كيف أُغيِّرُ كَلِمَةَ المُرورِ؟"  |  "كيف اغير كلمة المرور"
norm: "كيف اغير كلمه المرور"        |  "كيف اغير كلمه المرور"
lang=ar  score=1.000   -> رد فوري

in  : "الطابعه ما تطبع"             |  "الطابعة لا تطبع"
norm: "الطابعه ما تطبع"             |  "الطابعه لا تطبع"
lang=ar  score=0.583   -> "هل تقصد؟"

in  : "كم رصيد إجازاتي؟"            |  "وش رصيد الاجازات"
norm: "كم رصيد اجازاتي"             |  "وش رصيد الاجازات"
lang=ar  score=0.481   -> "لا أعرف" + طابور
```

السطر الثالث يشرح سبب وجود الطبقة الدلالية: السؤالان معناهما واحد، ودرجتهما اللفظية 0.481 فقط.

## أهم قرار في التصميم

**المشكلة:** كل بوت دعم مبني على نموذج لغوي يخترع إجابات عن أنظمة لم يرها.

**القرار:** مسار الرد الحي لا يستدعي النموذج إطلاقاً. ليست قاعدة تشغيل، بل بنية: ملفا `lib/engine.js` و `routes/chat.js` فيهما 0 استدعاء لـ `callBrain`، ولا يستوردان `lib/brain.js` أصلاً. الملف مستورد في 4 مواضع فقط، كلها خارج مسار الرد: عامل خلفية، ومدرّب، وممتحِن، ولوحة التدريب.

**التكلفة:** البوت يجيب فقط عما دُرِّب عليه. وقاعدة الإجابات تبدأ بـ 0 إجابة.

**العائد:** 0 إجابة مخترعة، و 0 طلب شبكة في مسار الرد. الرد يخرج من SQLite محلية.

النموذج يعمل خلف الكواليس فقط، وبشكل غير متزامن: يحكم على المطابقات المتوسطة ويُخزَّن حكمه في كاش، ويقترح صياغات بديلة **ليوافق عليها المدرّب**، ويترجم المتون.

## التشغيل

```bash
npm install     # ينزّل نموذج المتجهات مرة واحدة إلى data/models
npm start       # http://127.0.0.1:4600
npm run verify  # 40 اختبار E2E على قاعدة مؤقتة، ثم يحذفها
```

الخادم يستمع على `127.0.0.1` فقط، لا على كل الواجهات.

| المتغير | الوظيفة |
|---|---|
| `PORT` | المنفذ. الافتراضي 4600 |
| `SANAD_DB` | مسار قاعدة SQLite |
| `SANAD_NO_BRAIN=1` | يوقف كل استدعاءات النموذج. وضع الاختبار |
| `SANAD_NO_EMBED=1` | يوقف المتجهات، ويُبقي المطابق اللفظي وحده |
| `SANAD_BRAIN_CMD` | أمر النموذج الخارجي. يأخذ النص كأول وسيط ويطبع JSON. فارغ = لا استدعاء نموذج أبداً |
| `SANAD_BRAIN_ARGS` | وسائط إضافية بعد النص. الافتراضي `--json` |
| `SANAD_TG_TOKEN` | توكن بوت تيليجرام. اختياري، ويُحجب من كل السجلات |
| `SANAD_TG_ALLOWLIST` | المحادثات المسموح لها. غيرها يُسجَّل ويُرفض |
| `SANAD_TG_ADMIN` | معرّف محادثة المدرّب |

كل الأسرار من البيئة. لا مفتاح واحد داخل الكود.

قناة تيليجرام محدودة بـ 20 رسالة في الدقيقة لكل محادثة. والخادم يأخذ نسخة احتياطية كل 24 ساعة، ويحتفظ بآخر 14 نسخة.
